# 波波桌宠 (deskpet)

原创跨平台桌面养成宠物，灵感来自 QQ宠物，但形象/数值/玩法均为原创，无服务器、纯本地存档。

## 开发运行

```bash
npm install
npm run dev
```

会启动一个透明置顶的桌面宠物窗口（可拖拽、点击互动）和一个隐藏的功能面板窗口（双击宠物或点击托盘「打开面板」唤出）。

## 打包

```bash
npm run build:mac   # 产出 dmg / zip，已验证可在本机直接运行
npm run build:win   # 产出 NSIS 安装包，已在本机交叉构建验证生成成功（未在真实 Windows 上验证安装运行）
```

产物在 `release/` 目录下。

## 功能

- 桌面行走/拖拽/点击互动，气泡台词
- 饥饿/清洁/心情/体力数值随时间衰减，关闭重开按离线时长补偿
- 喂食、洗澡、睡眠、打工（计时赚金币经验）
- 商店购买食物/清洁用品/帽子/配色，背包穿戴
- 升级与三段进化（幼年/少年/成年，外观随之变化）
- 每日任务（喂食/清洁/打工/互动/小游戏），次日自动重置
- 「接星星」原创小游戏，结算金币与经验
- 系统托盘菜单：显示/隐藏、快速投喂、开机自启、退出

## 已知限制

- Windows 包仅在 macOS 上交叉构建验证通过（能正常生成安装包），未实机跑过 Windows 安装/运行，建议拿到 Windows 机器后再实测一遍
- 宠物窗口的桌面随机走动是在初始位置附近小范围漂移，未做多屏边界感知
